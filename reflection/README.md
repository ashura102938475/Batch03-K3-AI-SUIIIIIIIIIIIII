# Reflection

Mỗi thành viên tự hoàn thiện một file trước khi nộp. Nội dung cần viết bằng trải
nghiệm thật của chính người đó, không dùng AI để bịa vai trò hoặc bài học.

Mỗi file cần trả lời:

1. Tôi phụ trách phần nào và có thể giải thích đoạn code/quyết định nào?
2. AI hỗ trợ tôi ở đâu, và tôi đã kiểm tra đầu ra bằng cách nào?
3. Một failure hoặc feedback nào khiến tôi đổi quyết định?
4. Nếu có thêm một tuần, tôi sẽ ưu tiên điều gì và vì sao?
